# Agent marks (decorative elements)

Each agent has its own line-drawn shape language inside a soft glow (guide 4.2). The shared frame is a dashed outer circle and a blurred glass orb, and it keeps them one family:
- **Ivy:** crossing ellipses around a pink core.
- **Cooper:** meridian lines, pinched at the equator, on aqua.
- **Elliot:** nested arcs rising to a point of light, on periwinkle.
- **Lana:** mirrored concentric arcs forming an hourglass, on pink/peach.

Use a mark only with its own agent and its own gradient. Marks are full-color SVGs: never recolor or outline them.
