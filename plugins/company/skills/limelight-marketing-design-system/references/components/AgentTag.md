# AgentTag

The white pill that names an agent: under an orb ("{ Ivy }"), on pricing cards ("Influencer Manager") and in the roster ("Training").

- The consumer provides the text (children). Set `mono` for the braced Geist Mono style (an agent's first name under its orb). Leave it off for job titles and states.
- Set `live` to add the `status-live` dot. The dot is always read out as "live", so color is never the only signal.
- Site style: `label-s` (Geist 12px, line-height 1, -2%), `text-600`, 8/12 padding, 32px radius, `surface-100`, a faint 1px text shadow, and a soft lilac inner glow.
- Use it on agent gradients and light surfaces only.
