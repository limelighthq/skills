# Chip

A small outlined label for a category or a duration, placed next to a date: "Market Research", "33 Min".

- The consumer provides the text (children).
- Style: Geist 14/21 in `text-400`, a 1px 20%-black border, `radius-xs`, 1.6/12 padding.
- Use it only for metadata. It is not a button or a filter (for those, use `FilterTabs`), and it is not an eyebrow (for that, use `SectionTag`).
