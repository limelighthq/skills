# SectionTag

The small uppercase eyebrow in curly brackets that opens every site section: { YOUR NEW HIRES }, { THE PROBLEM }, { 7 DAYS FREE TRIAL }.

- The consumer provides the text (children). Write it in any case: CSS sets it in uppercase.
- Style: `label-m` (Geist 14px, -1%), `text-500` on `surface-200`, pill (32px radius), `shadow-tag`, and brackets in `surface-500`.
- Use one per section, above the `SectionHeading` title. Keep it to 2–5 words. The footer also uses it for column titles.
