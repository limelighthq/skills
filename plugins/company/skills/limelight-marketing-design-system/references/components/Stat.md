# Stat

A proof number over a faint dotted orbit, with a two-tone caption: "44% vs 13%" / "**Marketing spends** 3x more on labor than tech".

- The consumer provides `value`, `lead` (ink words) and the rest of the caption (children). Set `orbit={false}` to drop the orbit.
- Number: Host Grotesk 36px (`heading-l`, -3%), `text-600`, with the dotted orbit SVG behind it at 125% width. Caption: `body-l` in `text-500` with the lead in `text-600`, 72px below.
- Put 3–4 stats in a row with `surface-300` rules between them (wrap them in `.ll-stats`). They stack on phones.
- Use real, sourced figures only.
