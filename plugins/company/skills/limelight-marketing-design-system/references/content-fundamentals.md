# Content fundamentals

- Talk about agents as people on the team: "Meet Ivy", "Your new hires", "AI employees". Each agent has a first name and a job title: Ivy, Influencer Manager · Cooper, Customer Advocacy Manager · Elliot, Employee Social Manager · Lana, Social Intelligence Manager.
- Write in second person to the buyer ("what it takes off your plate"), in a calm voice and with short sentences. Use no hype, no exclamation-heavy copy and no emoji.
- Buttons and headings use sentence case: "Book a demo", "Meet AI employees", "Sign up". Put a trailing arrow only on text links ("See customer results →").
- Agent names can appear in braces as a label: `{ Ivy }`. Use this only in agent tags, never in running text.
