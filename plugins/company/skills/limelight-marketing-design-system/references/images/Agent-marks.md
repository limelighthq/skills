# Agent-marks

Each agent's decorative element (guide 4.2), exported from the Figma "Decorative Element" slide as full-color SVG (240×240, glow + line art). Use each one only with its own agent and gradient. Do not recolor these: they are not single-ink.

- `ivy-mark.svg`: Ivy: crossing ellipses, pink core, blue glow.
- `cooper-mark.svg`: Cooper: meridian lines on aqua.
- `elliot-mark.svg`: Elliot: nested arcs to a point of light, periwinkle.
- `lana-mark.svg`: Lana: mirrored arcs (hourglass) on pink/peach.
