# Agent-portraits

The four AI-agent portraits (transparent PNG, 640×800), copied from the Limelight marketing system. D does not use these files: it crops Ivy and Elliot out of the Agent-references images. Use these portraits only for Cooper and Lana, which D does not show, through `AgentFace src` (round, same sizes as D's crops: 34px rail, 18px selector, 96px signature). Always pair a portrait with the agent's name, visible or as its accessible name.

- `ivy-portrait.png`: Ivy, Influencer Manager
- `cooper-portrait.png`: Cooper, Customer Advocacy Manager
- `elliot-portrait.png`: Elliot, Employee Social Manager
- `lana-portrait.png`: Lana, Social Intelligence Manager
