# Overview

The Limelight product app, as the live Proposal D prototype renders it. D is the source of truth for the V2 UI: this system carries D's fonts, weights, case, radii, surfaces, colours, shadows, lucide icons, spacing, copy and shell behaviour. It departs from D only where the agent-platform CLAUDE.md requires a fix (text contrast, control and mark contrast, a visible focus ring, the icon size floor, the disabled-state rule, and three D defects). Every departure is listed in **D exceptions** below. Use this system for every screen inside the product. The Limelight marketing system covers the website.
