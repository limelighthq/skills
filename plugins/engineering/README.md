# engineering

Skills for engineers. They work in any repo. Skills that depend on one repo's layout or tooling stay in that repo.

| Skill | Use it to |
| --- | --- |
| [`annotate-ui-screenshots`](skills/annotate-ui-screenshots/SKILL.md) | Produce annotated screenshot evidence for a UI change. Needs Python 3.10+ with Pillow. |
| [`deep-module-scan`](skills/deep-module-scan/SKILL.md) | Find shallow-module clusters and rank refactor candidates. Reports only. |
| [`handoff`](skills/handoff/SKILL.md) | Package a session so a fresh session or a colleague can resume it. |
| [`one-percent-better`](skills/one-percent-better/SKILL.md) | Find and open one small, evidence-backed improvement PR. |
| [`recap`](skills/recap/SKILL.md) | Get a terse step-by-step recap of the current session. |
| [`research`](skills/research/SKILL.md) | Investigate primary sources and produce a cited note, inline or with a background agent. |
